📊 วิเคราะห์เส้นทางอิทธิพล (Path Analysis)

ประมาณค่าด้วย OLS บนคะแนนเฉลี่ยของตัวแปรสังเกตได้แต่ละกลุ่ม · ทดสอบ Indirect effect ด้วย Sobel test

1. นำเข้าข้อมูล (Excel / CSV)

แถวแรกต้องเป็นชื่อคอลัมน์ ข้อมูลเป็นตัวเลข

2. ตัวแปรอิสระ (X)

3. ตัวแปรส่งผ่าน (M)

4. ตัวแปรตาม (Y)

5. ความสัมพันธ์ระหว่างตัวแปร

จับคู่เส้นทางเอง: เลือกตัวแปรต้นทาง → ปลายทาง แล้วกดเพิ่ม · X → Y = Direct effect · X → M → Y = Indirect effect (ระบบคำนวณอิทธิพลทางอ้อมจากเส้นทางที่คุณเชื่อมไว้)
